# 验收用例（先于技能正文编写）

## 应触发
1. 「帮我把竖版视频做成1:1和16:9，带logo和卖点」→ 收集品牌素材、文案和角色参考，生图设计两个完整套版，再按授权范围合成。
2. 「直接用生图插件出套版，别自己拼」→ 整张设计由 image_generate 生成；不以代码重排文字、图标、角色。允许正式合成时替换视频占位区。
3. 「视频边缘贴边，不要边框」→ 视频高度填满画布，方版左贴边、横版居中；无外边距、阴影、圆角框。
4. 「先让我看看翻译对不对」→ 只给简洁翻译和图标方向，等待文案反馈，不擅自生图或导出。
5. 「可以，终版视频为这个路径，包装好输出到成品目录」→ 使用最新明确指定的源文件及已认可套版，不重复要批准；输出两版视频并检查原音轨一致。

## 不应触发
1. 「给视频加逐词字幕和选择定格」→ mm-workbench-v5；属于视频内部互动包装。
2. 「帮我写马尔福的英语台词」→ shortdrama-copy；属于剧情和本地化。
3. （已合并）套版、命名、上传现在同属 xmp-upload；只套版时走「只套版、不上传」分支，不改名不上传。
4. 「做一个网页落地页」→ web-design-engineer；不是静态套版视频。
5. 「单独生成一个角色头像」→ image-gen；不需要多比例套版流程。

## 必须通过的回归场景
- 图片生成器返回的尺寸不是请求值：读取真实像素，依据实际边界定位视频占位区，不硬编码假设。
- 用户更换终版视频：以新路径为准，不选择旧导出的最新文件。
- 音频比视频多一个 AAC 包：输出不使用全局 -shortest；音频包哈希与源文件一致。
- 请求先出图：只交设计预览，不误称成片或擅自继续合成。
- 用户已认可设计并要求导出：不再次等待确认。
- 生成的文字/Logo错误：通过图片编辑修正，不悄悄手工拼接文字。
- 无音轨视频：正常输出静音成片，检查报告标明源无音轨。
- 输出文件已存在：拒绝覆盖，另用版本文件名。
- 原视频非9:16：不得默认拉伸；根据真实比例重新确定视频区，必要时明确裁切选择。

## 可执行验证
运行 `python tests/smoke.py`：创建临时合成源（音频略长于视频）、生成占位背景，导出两个比例并验证尺寸、帧数、解码和音频包哈希；另测无音轨源与禁止覆盖。不会使用生产素材或调用付费生图。
路由用例通过人工逐条对照正文验证，不将静态阅读宣称为自动触发测试。
